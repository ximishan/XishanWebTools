# 西山工具箱微信小程序

原生微信小程序版本，当前已实现“线稿文字生成器”。所有文字和图片均在设备本地 Canvas 中处理，不依赖后端服务。

## 已实现

- 卡片式工具箱首页，工具入口由 `utils/tools.js` 集中配置。
- 线稿、断裂、局部干扰、字符错位、电路细节、噪点和模糊效果。
- 3:4、9:16、1:1、16:9 四种输出比例。
- 默认渐变、纯色、透明和用户上传图片四种背景。
- 上传背景的铺满、完整显示、拉伸、缩放、位置、透明度和模糊设置。
- PNG 导出并保存到系统相册。
- 微信原生广告配置层和广告位组件已预留，默认完全关闭。

## 导入微信开发者工具

1. 使用微信开发者工具导入仓库中的 `miniprogram` 目录。
2. 首次预览可继续使用 `touristappid`；正式开发时在 `project.config.json` 中替换成自己的 AppID。
3. 使用真机预览测试相册选择、透明 PNG 和保存权限。

## 新增工具

1. 在 `pages/` 下创建新页面。
2. 在 `app.json` 的 `pages` 中登记页面路径。
3. 在 `utils/tools.js` 中添加工具卡片配置。

只有 `enabled: true` 的工具会显示在首页，避免未完成功能被误认为已经可用。

## 广告

广告默认关闭，不包含虚假或测试广告位。开通微信流量主后，按照 `docs/AD_INTEGRATION.md` 填入真实广告位 ID 即可启用。
